meWYSE

Editor de bloques al estilo Notion. ECMAScript 5 puro, sin dependencias, un solo archivo.

ES5 Compatible Zero Dependencies Single File Markdown Support

Funcionalidades

  • Funciona con cualquier elemento: textarea, div, span o cualquier HTML
  • Sistema de bloques: Inspirado en Notion, cada linea es un bloque independiente
  • 18 tipos de bloques: Parrafo, titulos, citas, codigo, listas, checklists, tablas, imagenes, video, audio, separadores, salto de pagina, aviso, desplegable, indice
  • Formato enriquecido: Menu flotante con negrita, cursiva, colores, enlaces y mas
  • Menciones (@) y etiquetas (#): Escribe @ o # para insertar con autocompletado
  • Resumen y estadisticas: Indice de navegacion, conteo de palabras y tiempo de lectura
  • Menu slash (/): Menu contextual al estilo Notion para cambiar tipos de bloque
  • Atajos de teclado: Ctrl+B/I/U/Z/Y/K para formato rapido y undo/redo; Ctrl+A selecciona todo el contenido
  • Ajuste de texto: opcion wordWrap (y boton en la toolbar) para que el contenido largo salte de linea dentro del bloque
  • Exportacion multiple: JSON, HTML, Markdown y texto plano
  • Soporte Markdown: Importar y exportar contenido Markdown
  • Internacionalizacion: Espanol, ingles y traducciones personalizadas
  • Temas y dark mode: Auto-deteccion del sistema + tema personalizable
  • Content Styles: Opcion para heredar estilos CSS de la pagina
  • Accesibilidad: ARIA attributes, focus-visible, keyboard navigation

Editor Basico

Editor aplicado a un textarea. Ideal para formularios y campos de texto enriquecido.

var editor = new meWYSE({
  target: '#basicEditor',
  onChange: function(data) {
    console.log('Contenido:', data.plainText);
  }
});

// Por defecto no toma foco. Para enfocar manualmente:
editor.focus();        // primer bloque
editor.focus(blockId); // bloque especifico

// Para auto-foco al inicializar:
// new meWYSE({ target: '#editor', autoFocus: true });

Herramientas de selección (selectionTools)

      
Las herramientas que necesitan una selección para tener sentido (sub/superíndice, mayúsculas, quitar formato, enlace, color, fuente y tamaño) no tienen por qué ocupar la toolbar cuando no se pueden usar. La opción selectionTools decide dónde aparecen. Negrita, cursiva, subrayado y tachado quedan siempre en la toolbar (funcionan con solo el caret y reflejan su estado activo con fondo resaltado).


      
1. 'floating' (por defecto)

      
Esas herramientas no se pintan en la toolbar; aparecen en el menú flotante al seleccionar texto (aunque la toolbar esté activa). La alineación, que es de bloque, se queda en la toolbar.

      

        Selecciona una palabra para ver el menú flotante con color, fuente, tamaño, enlace… Pulsa negrita sin seleccionar nada y empieza a escribir: el texto sale en negrita y el botón queda resaltado.
      

      
var editor = new meWYSE({
  target: '#selectionFloatingEditor',
  toolbar: true
  // selectionTools: 'floating'  // valor por defecto
});

      


      
2. 'toolbar'

      
Se pintan en la toolbar pero deshabilitadas (en gris) hasta que hay una selección de texto; al colapsar el caret vuelven a deshabilitarse.

      

        Fíjate en color, fuente, tamaño, enlace, mayúsculas… salen en gris. Selecciona texto y se habilitan; negrita/cursiva/subrayado/tachado están siempre activas.
      

      
var editor = new meWYSE({
  target: '#selectionToolbarEditor',
  toolbar: true,
  selectionTools: 'toolbar'
});

      

    


    
    

      
Acciones personalizables (actions / disabledActions)

      
Toolbar, menú flotante y atajos de teclado comparten un registro central de acciones. Eso permite añadir botones propios, desactivar acciones estándar y cambiar el comportamiento de una estándar — sin tener que redeclarar el resto de la toolbar.


      
1. Añadir acciones propias

      
Cada acción define icon, tooltip, position, placement y su onClick. La posición es relativa a una acción estándar: { after: 'bold' } la coloca dentro de ese grupo, y añadiendo group: 'new' crea un grupo propio (con separadores). Sin position va al final.

      

        MAY (junto a negrita) y # (contar) solo se habilitan al seleccionar texto (requiresSelection). Fecha está en su propio grupo tras las de inserción. H1? solo se habilita con el cursor en un título 1 (isEnabled). Selecciona texto y mira también el menú flotante: MAY y # aparecen ahí (placement: 'both').
      

      
var editor = new meWYSE({
  target: '#actionsEditor',
  toolbar: true,
  actions: [
    // Dentro del grupo de negrita, y tambien en el menu flotante
    { name: 'mayus', icon: 'MAY', tooltip: 'Pasar a MAYUSCULAS',
      placement: 'both', position: { after: 'bold' },
      requiresSelection: true,
      onClick: function(ctx) { ctx.editor.applyCaseTransform('upper'); } },

    // Cuenta palabras/caracteres de la seleccion (o de todo el documento)
    { name: 'contar', icon: '#', tooltip: 'Contar',
      placement: 'both', position: { after: 'mayus' },
      requiresSelection: true,
      onClick: function(ctx) {
        var t = ctx.selection.text || ctx.plainText;
        alert(t.trim().split(/\s+/).length + ' palabras, ' + t.length + ' caracteres');
      } },

    // Grupo PROPIO (separadores) justo despues del grupo de insercion.
    // icon admite SVG en crudo, clave de WYSIWYG_ICONS o texto ('MAY', '#')
    { name: 'fecha', icon: '<svg ...>', tooltip: 'Insertar fecha',
      position: { after: 'audio', group: 'new' },
      onClick: function(ctx) {
        document.execCommand('insertText', false, new Date().toLocaleDateString());
      } },

    // Habilitada solo si el cursor esta en un Titulo 1
    { name: 'soloh1', icon: 'H1?', tooltip: 'Solo en Titulo 1',
      isEnabled: function(ctx) { return !!ctx.block && ctx.block.type === 'heading1'; },
      onClick: function(ctx) { alert('Bloque: ' + ctx.block.type); } }
  ]
});

      


      
2. Desactivar estándar y cambiar su comportamiento

      
disabledActions quita acciones sin redeclarar la toolbar: desaparecen del botón, del menú flotante y de su atajo. Y una acción de actions cuyo name sea uno estándar lo sobrescribe: el callback recibe ctx.callDefault() para envolver el comportamiento original en vez de reemplazarlo.

      

        Aquí tachado e imprimir están desactivados (tampoco funciona Ctrl+Shift+X). Y negrita está sobrescrita: registra la llamada en el panel de abajo y luego aplica la negrita real con ctx.callDefault() — pruébalo con el botón, desde el menú flotante y con Ctrl+B (mira el campo source).
      

      
var editor = new meWYSE({
  target: '#actionsOverrideEditor',
  toolbar: true,
  // Quitar estandar (boton + menu flotante + atajo)
  disabledActions: ['strikethrough', 'print'],
  actions: [
    // Mismo `name` que una estandar => la sobrescribe
    { name: 'bold', onClick: function(ctx) {
        registrar(ctx);        // ctx.action, ctx.source, ctx.selection.text...
        ctx.callDefault();     // y ejecuta la negrita original
      } }
  ]
});

Detección de cambios (dirty tracking)

      
Este editor se monta sobre un <textarea> que ya trae HTML (contenido guardado previamente). isDirty() / hasChanges() indican si el contenido cambió respecto a la línea base "limpia", que se captura tras la conversión HTML→bloques. Así, si entras con el foco y sales sin editar nada, NO se reporta cambio. El payload de onBlur incluye hasChanges.

      

        Prueba: haz clic dentro del editor y luego fuera sin tocar nada → el estado sigue en «sin cambios» (la conversión HTML→bloques no cuenta). Ahora edita cualquier texto → mientras escribes pasa a «con cambios»; al hacer clic fuera, el onBlur de este demo llama a resetDirty() (simulando guardar) y vuelve a «sin cambios».
      

      
var editor = new meWYSE({
  target: '#dirtyTrackingSource',   // textarea ya con HTML
  toolbar: true,
  onBlur: function (data) {
    if (data.hasChanges) {          // o data.editor.hasChanges() / data.editor.isDirty()
      guardar(data.html);           // solo si realmente cambio algo
      data.editor.resetDirty();     // referencia al editor en el payload (sin variable externa)
    }
  }
});

Bloques de tipo desconocido

      
Se carga un JSON con un bloque cuyo type el editor no reconoce (aquí chart, como si viniera de una versión más nueva o de un plugin). En vez de perderlo o aplanarlo a un párrafo, meWYSE lo preserva íntegro: lo muestra como un placeholder de solo lectura y lo re-emite tal cual en getJSON(). Así puedes cargar y volver a guardar sin destruir contenido que no entiendes.

      

        El bloque chart aparece como «Bloque no reconocido». Pulsa Ver JSON: el bloque sigue ahí con su data intacto (round-trip fiel).
      

      
editor.loadFromJSON([
  { type: 'heading2', content: 'Informe' },
  { type: 'paragraph', content: 'Texto normal.' },
  { type: 'chart', data: { kind: 'bar', values: [4, 8, 15] }, caption: 'Ventas' },
  { type: 'paragraph', content: 'Sigue el documento.' }
]);
// El bloque 'chart' se conserva integro y getJSON() lo re-emite tal cual.

Callbacks onFocus / onBlur

      
Los callbacks onFocus y onBlur se disparan solo al entrar/salir del editor (no al moverse entre bloques internos ni al usar la toolbar/menus/modales). Útil para validaciones al perder foco.

      
var editor = new meWYSE({
  target: '#focusEditor',
  toolbar: true,
  onFocus: function(data) {
    console.log('focus en bloque', data.focusedBlockId, data.focusedBlockType);
  },
  onBlur: function(data) {
    if (!data.plainText.trim()) alert('El editor no puede estar vacío');
  }
});

Altura configurable

      
Controla la altura por opciones: minHeight, maxHeight y autoExpand (crece con el contenido).

      
// 1) Crece con el contenido, hasta 320px y luego scroll interno
new meWYSE({ target: '#autoHeightEditor', toolbar: true,
             autoExpand: true, minHeight: 100, maxHeight: 320 });

// 2) Sin tope: crece indefinidamente (scrollea la página)
new meWYSE({ target: '#growEditor', autoExpand: true, minHeight: 80 });

// 3) Caja fija: alto tope 180px con scroll interno (sin autoExpand)
new meWYSE({ target: '#fixedHeightEditor', toolbar: true, maxHeight: 180 });

// 4) Solo suelo: alto minimo 260px (crece si hay mas contenido)
new meWYSE({ target: '#minHeightEditor', toolbar: true, minHeight: 260 });

// 5) Valores CSS en string (vh/em) tambien valen
new meWYSE({ target: '#vhHeightEditor', minHeight: '10em', maxHeight: '35vh' });

      
1) autoExpand + minHeight 100 / maxHeight 320

      

      
2) autoExpand sin tope (minHeight 80)

      

      
3) maxHeight 180 (caja fija con scroll)

      

      
4) minHeight 260 (solo suelo)

      

      
5) string CSS: minHeight '10em' / maxHeight '35vh'

      

    


    
    

      
Vídeo con previsualización

      
El bloque de vídeo guarda solo la URL. Se muestra una previsualización (miniatura + play) y el iframe se carga solo al pulsar play. Como una imagen: selecciónalo para ver el handle y ajustar dimensiones.

      

        Inserta un vídeo con el botón de la toolbar (o /video) y pega una URL de
        YouTube/Vimeo. En el modelo, el contenido es solo la URL: { type:'video', content:'https://...', width, height }.
      

      

    


    
    

      
Bloques desactivados (disabledBlocks)

      
Desactiva tipos de bloque en la UI: no aparece su botón en la toolbar, se filtran del menú slash y no se crean al pegar HTML. En este editor están desactivados vídeo, audio y tabla.

      

        Abre el menú slash con / o mira la toolbar: no verás vídeo, audio ni tabla.
        No afecta al contenido cargado por blocks/loadFromJSON.
      

      
new meWYSE({
  target: '#disabledEditor',
  toolbar: true,
  disabledBlocks: ['video', 'audio', 'table']
});
